E(x) = (x + k) mod 26

5. Elliptic Curve Cryptography — Encryption and Decryption

This experiment uses the secp256k1 elliptic curve:

y² = x³ + 7 (mod p)

The public key is generated by elliptic-curve scalar multiplication:

Q = dG

An ephemeral private scalar r produces R = rG and a shared point S = rQ = dR. The shared point is hashed with SHA-256 to derive an AES-GCM encryption key.

This is a simplified educational hybrid encryption scheme rather than an Ethereum wallet implementation.

Statistical interpretation

The Caesar cipher is a deterministic permutation of the alphabet. Consequently, the relative letter frequencies and Shannon entropy of the alphabetic plaintext are preserved by encryption.

In contrast, authenticated encryption with AES-GCM obscures recognizable linguistic patterns. Frequency analysis of English or Italian letters cannot recover the ECC private key.

The Caesar cipher is vulnerable because of both its small key space and its preservation of language statistics. The toy ECC scheme is vulnerable because its private key was deliberately restricted to a small range.

Alternative Caesar attacks include exhaustive search and n-gram scoring. Unlike the Caesar statistical attack, ECC key enumeration does not exploit language frequencies.
